# Top-Down Camera Mod — Minecraft 1.20.1 (Fabric)

Hotline Miami-style вид сверху. Клиентский мод. Тоггл на F6.

## Как собрать
Не нужно ничего собирать вручную — GitHub сам соберёт при загрузке кода (см. вкладку Actions).

## Как установить
1. Скачай артефакт `topdown-jar` из последнего успешного run в Actions
2. Распакуй, возьми `topdown-1.0.0.jar`
3. Установи Fabric Loader для 1.20.1
4. Положи в `.minecraft/mods/` этот jar и Fabric API
5. Запусти игру, нажми F6
